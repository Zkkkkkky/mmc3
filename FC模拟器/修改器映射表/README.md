# 新DC篇修改器映射表

本目录由 `python tools\export_dc_modifier_mappings.py` 从当前基准 ROM 和用户提供的 `默认配置文件/` 确定性生成，文件均为 UTF-8。

- `新DC完整码表.tbl`：2915 条实际可解码 Token；可由新版剧情编辑器直接载入。
- `新DC字模地址映射.csv`：保留旧配置的 3328 行字模地址、Token 和字符关系。
- `新DC_ROM名称与表地址映射.json`：255 个机体、254 个武器、200 个人物选择器、100 张地图及 200 个战斗音乐选择器。
- `旧修改器配置名称索引.json`：12 组旧修改器名称表，保留行号即 ID；原资料中的空白、`未命名` 和 `未知` 均带状态，不会被猜测性改名。

基准 ROM SHA-256：`82C218275459D53C0F306F6BC036C4797316976E0FA7AD1D5A8247E338995B8E`。若 ROM 哈希变化，应重新生成并重新验证表地址。
