# 参考修改器 UI 探针总结（SRW2_patched.exe）

> 任务 #7 产物 | 探针库：`tools/research/legacy_ui_probe.py`（56KB，可复用）
> 运行隔离：exe 及默认配置文件整套副本位于 `output/build/legacy-ui-probe/`（收尾已清理），ROM/sav 均用副本（probe.nes / probe.sav），references/ 全程零写入。
> 产物统计：screenshots/ 131 张 PNG（约 11 MB），controls/ 130 个控件树 JSON + controls_summary.md（约 760 KB，全窗口控件汇总表）。

## 1. 方法概述

- **技术栈**：.venv Python + ctypes 调 Win32 API（EnumWindows/EnumChildWindows/GetDlgCtrlID/PrintWindow(PW_RENDERFULLCONTENT)）；DPI aware；对目标 exe 设 WIN7RTM 兼容层（注册表条目，收尾已删除）。
- **触发方式**：WM_COMMAND（菜单项 ID 20001-20025）/ BM_CLICK（按钮控件 ID）打开对话框；通用文件对话框用"文件名 Edit + WM_SETTEXT + IDOK"填路径。
- **页签切换**：参考修改器的 CPageControl 非标准 Tab 控件，TCM_SETCURSEL 无效；实际有效方式为切换其子容器（TTabSheet/Panel 类 Button 容器）的 ShowWindow 显隐。
- **截图**：PrintWindow 主路径；弹出菜单用全屏 BitBlt 裁剪。

## 4. 否定证据清单（1:1 复刻决策输入）

1. **编辑图块属性（660）无对话框**：BM_CLICK / WM_COMMAND / 真实鼠标点击（含先点选图块再触发）/ Space / Enter 六种方式均无新窗口。若参考版确有此功能，可能依赖未满足的前置状态（如特定图块选中态）或该按钮在参考版中即无响应。
2. **地图画布无右键菜单**：真实右键送达画布（WindowFromPoint 命中校验通过）后无 #32768 菜单创建。
3. **无未保存提示、无自动备份**：脏数据状态下直接 WM_CLOSE 主窗口与关闭按钮，无确认弹窗；工作目录无新增备份文件。
4. **导出头像（20018）无法触发**：隔离复现（单独 post 40s/90s/300s、Ctrl+L 键序、与 660 组合点击）均无对话框。历史会话中曾出现 1-3 分钟延迟弹出的'导出机体'标题 #32770（被诊断例程捕获为 `DIAG_阻塞弹窗1`），但无法稳定复现——可能与菜单轮询压力或程序内部计时逻辑有关。
5. **"运动规律模拟器"与"动画测试"按钮不存在**：地图动画-规律页按钮全量枚举为：确定(310)/取消(300)/动画拼图(610)/代码编辑(150)/添加(330/320/120)。需求文档中这两个名称应对应"物理拼图"与"请输入动画指针"对话框。
6. **更改倍数触发运行时错误**：属性计算器-更改倍数输入 750/760 后确认 → 易语言运行时错误弹窗"数组成员引用下标超出定义范围"（错误代码 1，`D4_属性计算器_更改倍数` 为证）。参考版该路径存在 bug，复刻时不应照搬。

## 5. 关键技术发现（探针方法论，复用时必读）

1. **易语言通用文件对话框为"隐藏创建"**：菜单命令 post 后 0.2-0.3s，#32770 对话框即创建但 WS_VISIBLE=False（程序稍后才 ShowWindow）。所有 `visible_only=True` 的窗口轮询都会漏掉。解法：`enum_top_windows(pid, visible_only=False)` 轮询 + `ShowWindow(hwnd, SW_SHOW)` 强制显示 + force_foreground → PrintWindow。此法是捕获 `D11_导出机体_保存对话框` 的关键。
2. **CPageControl 页签切换 = 子容器显隐**：标准 TCM_SETCURSEL 对易语言 CPageControl 无效；有效做法是枚举其子容器（TTabSheet 类）并 ShowWindow 目标页容器。
3. **易语言运行时错误弹窗关闭 = 进程退出**：错误对话框点确定/WM_CLOSE 后进程随之死亡，探针需 ensure_session 自动重启逻辑。
4. **real_click_at 传子控件 hwnd 会误判**：WindowFromPoint 校验用 GA_ROOT（=主窗口）比对传入 hwnd，故应传主窗口 hwnd + ClientToScreen 换算的 client 坐标。
5. **点击前必须刷新已知窗口集**（snapshot_known），否则 wait_new_top 会把已存在的旧窗口误判为新对话框。
6. **控件 rect 字段为 left/top/width/height**（非 x/y）；菜单树 JSON（B03）为 list 根结构而非 dict。
