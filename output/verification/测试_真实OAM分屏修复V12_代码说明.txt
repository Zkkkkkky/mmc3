一、恢复战斗 OAM 生成函数入口原代码
文件偏移 0x07D0F5，CPU $D0E5
原：20 67 F4 EA        JSR $F467 / NOP
新：A9 04 85 15        LDA #$04 / STA $15

原因：V10/V11 在子精灵坐标尚未计算时检查对象原点，旋转武器的原点没有进入 UI，无法触发。

二、把判定调用移到战斗子精灵 OAM 生成完成之后
文件偏移 0x07FB2C，CPU $FB1C
原：A5 73 38           LDA $73 / SEC
新：20 11 F5           JSR $F511

新例程返回前补做原来的 LDA $73 / SEC，所以调用者原有逻辑不变。

三、寄存器保护包装例程（CPU $F511，使用既有空白区）
  TXA / PHA
  TYA / PHA             保存 X、Y
  JSR $F467             执行真实 OAM 判定
  PLA / TAY
  PLA / TAX             恢复 Y、X
  LDA $73 / SEC / RTS   补做挂接点原来的指令

四、新判定例程（使用既有空白区，不扩容 ROM）
CPU $F467 起：
  LDX #$40              从 OAM $0240 开始，跳过 UI 保留的前 16 个精灵
循环：
  LDA $0200,X           读取已经计算完偏移的真实子精灵 Y
  CMP #$80
  BCC 下一个
  CMP #$F0
  BCC 已进入UI          只接受 $80-$EF；$F0-$FF 是隐藏精灵
下一个：
  INX / INX / INX / INX 每个 OAM 项 4 字节
  BNE 循环              扫描 $0240-$02FF
  LDY #$14              没有跨界精灵：下方恢复 UI 的 R1
  JMP 写入分屏表
已进入UI：
  LDY $04D9             有跨界精灵：复制本帧顶部实际 R1

五、写入分屏表
CPU $F486 起：
  LDX #$09
循环：
  LDA $03BC,X
  CMP #$F0
  BNE 下一个
  TYA
  STA $03C6,X           只改 R1 分屏项
下一个：
  DEX
  BPL 循环
  RTS
