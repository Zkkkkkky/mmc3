## 结论

此前记录的 `0.001—0.18 秒` 是同进程离屏热点诊断，不是用户等待时间，不能再用于“页面打开耗时”的对外结论。按需主页面把 ROM 确认到主地图完整绘制从此前同机约 `4.26 秒` 降到本次 `2.34 秒`；地图动画首次打开由此前约 `2.76 秒` 降到 `2.17 秒`。数据库进一步由约 `3.2—3.8 秒且先白屏` 降到约 `2.75 秒且直接显示完整机体页`；仍有继续压缩空间，后续优化必须继续用本表的方法复测。
