# M14 剧情事件人工验收清单

## 1. 验收边界

本清单用于验收 M14 当前安全交付范围：六页签、关卡设置三类事件列表、等长参数编辑、行动索引/搜索、前四条劝降规则、地图事件、剧情/胜利文本编辑以及整窗确定/取消事务。

以下范围不在本轮通过条件内，也不得因本清单通过而升级为“已对齐”：

- 标题拼图写回（F-079）和胜利文字关卡索引写回（F-081）保持只读；
- 独立行动表（F-080）及接上/接下变长插入（F-082）延期；
- 六类事件剩余空间检查（F-083）只恢复逐字入口。参考版点击后的显示形态与分区算法尚无动态证据，按钮必须保持禁用；
- 所有写入能力仍待参考 EXE 黄金差分，人工通过不等于“已实现（已对齐）”。
