## 当前 ROM 的定位证据

只读源：`references/rom/source/新DC.nes`，SHA-256 `267CFA5E6273E0FE3557D5339B0E50172BCF25475283944C7E8372276FB3493C`。修改器测试基线为 `output/rom/DC_kuorong_464K.nes`。本次没有写入参考 ROM、生成 ROM 或 IPS。

| 资源 | 选择器 / 描述符 | 16 KiB 首 Bank / 目录 | 文件指针表 | 指针数 |
|---|---|---|---|---:|
| 地图动画 | `$62 / F2 28` | `$28 / 2` | `$05200C` | 153 |
| 我方武器动画 | `$60 / F0 22` | `$22 / 0` | `$044030` | 256 |
| 敌方武器动画 | `$61 / F0 20` | `$20 / 0` | `$040030` | 256 |
| 背景规律 | `$23 / 52 00` | `$0A / 2` | `$0160D1` | 106 |
| 地图运行规律 | `$68 / C5 07` | `$18 / 5` | `$0333A0` | 157 |
| 地图组图规律 | `$40 / C3 00` | `$18 / 3` | `$031A90` | 249 |

这些数量是指针槽位数，包含共用记录及只含结束码的槽位，不代表同样数量的独立动画。目录与指针边界经当前 ROM 逐项校验；文件换算为 `16 + 首 Bank × $2000 + CPU 地址 − $8000`。资源描述符来自活动固定 Bank 的 `$F3E2` 表；扩容版使用 `$7F`，旧兼容版使用 `$3F`。

验证用反汇编入口：

- `$FD4F–FD84`：描述符、目录索引、16 位小端指针的三级加载；`$FE33–FE52` 区分旧式描述符与 `F0` 以上的扩容描述符。
- `$FEDB`：`E0` 读取图库号写 `$04D8`；`E1` 写 `$04D9`。
- `$E84A–E884`：等待与 `F0–FF` 指令分发；`00` 等待计数减一后变成 `$FF`，因此按 256 帧显示。
- `$EB4F`：`F0` 调色板写入，长度由第二个参数决定；`$EBF0`：`F2` CHR 配置写入。
- `$EC21`：`F4` 写 `$004C`，同时适用于音乐和音效命令。
- `$ED53–EE13`：`F8/F9` 创建物体及组图/X/Y运行资源引用。对象号的 `$80/$40` 位表示坐标来自事件参数队列；`$C583` 读取参数队列时不额外消耗脚本字节。
- `$EE55`：`FD` 的有符号 X/Y 屏幕位移；`$EEF9`：`FE` 循环次数和绝对跳转；`$EF21`：`FF` 结束。
- `$E8CC–E95F`、`$E960–EB4F`：帧序列与 X/Y 轴序列的不同命令集；帧序列 `FB count relative` 和坐标序列 `83 count relative` 的跳转字节保持不变。

资料入口为 `page_325.html`、`page_1188.html`、`page_1189.html`、`page_1191.html`、`page_1192.html`。它们只用于理解协议，不直接采用旧地址。比如当前源已把地图动画移至 `$052xxx`、武器双方移至 `$044xxx/$040xxx`，与原版资料不同。


这与截图的图库 `$0A`、颜色 `28 17 20`、等待 1 帧、物体 `$0F`、运行规律 `01/02/02`、音效 `$02`、等待 29 帧、恢复图库 `$08` 和原色一致。界面把 `F1` 更新动作单独显示，因此为 11 行；旧修改器将其合并进颜色动作，并把物体创建与规律调用分行。

## 已接通的操作

- 地图页直接显示真实动画列表、指令、原始字节、地址、长度及共享 ID。选择指令即可改已验证参数，也可打开“代码编辑”输入等长十六进制代码。
- 可改调色板中的直接颜色、等待帧数、图库号、坐标、音乐/音效命令与循环次数。操作码、变量长度字段、资源指针、引用与跳转目标保持原值。非法字节或长度会阻止换项和确定，不丢弃输入。
- 规律页显示背景、运行、组图三栏真实代码。按实际地图动画调用确定运行规律是帧序列还是 X/Y 位移；能确定单一解释的记录允许等长修改帧 ID、位移、音效和循环次数。共享、混用或没有确定调用方式的记录保留只读。
- 组图规律可修改最前两个有符号起始 Y/X 坐标字节。其后的图块与拼图指令不改写。
- 调用页显示当前脚本 Bank `$1C/$1D` 中的 `38 02 id` 调用位置、当前动画和跳转按钮。前缀为已核对的 `2D 1D 03` 或 `2D 1D 0B` 完整设置/调用序列时可更换已有动画 ID；其余仅字节匹配的位置保留只读，不把搜索结果直接当作可写脚本。动态参数 `$FF` 不作为静态动画 ID 编辑。未确认的精神/地图武器名称关联不凭地址猜测。
- 武器页可嵌入 `WeaponAnimationWidget` 查看并编辑真实的我方、敌方脚本。共同支持共享记录提示和等长参数校验。
- 地图窗口内为独立草稿，确定时合并为一次工程事务；取消不修改工程。武器组件由数据库页面统一管理草稿及事务。均支持撤销/重做、`.dcmod` 保存重载和独立 ROM/IPS 导出。
