## 3. 已自动覆盖的边界

- 两份 8192 字节 FCEUX 实际存档的结构解码、活动关卡与战场人数。
- 三槽起点 `$1C81/$1D7E/$1E7B`、`$FB` 长度和 `$1D7C/$1E79/$1F76` 校验和。
- 无操作编码逐字节恒等；槽 1 首行 EXP `3884→3885` 仅变化 `$1D5C` 和校验和字节 `$1D7C`。
- 窗口标题、四按钮状态、两张 11 列表、错误尺寸拒绝、写入与落盘分离、备份和重开。

## 4. 明确只读、延期或未验证范围

- 活动 SRAM 不保存逐敌机体 ID 或基础金钱；这两列只能由当前 ROM 关卡部署匹配后只读推导，不得写入其他字节冒充。
- 参考 EXE 的存档窗口是无独立可定位句柄的模态子窗；当前自动化只完成了打开与界面取证，未把第 16 步冒充为通过。
- 实现侧报告和自动测试不等于用户验收；本表的“结果”和最终签收保持空白。
