# 新DC修改器开发记录

本文件从 2026-09-15 起作为持续开发日志，按时间顺序**只追加新条目**，不重写历史条目。正式执行队列见 `docs/需求拆分/README.md` §4.1；需求与功能状态基准仍是 `docs/SRW2修改器1比1复刻需求文档.md`，本日志不替代模块文档第 8 节、用户使用说明或用户验收签核。

每次开发工作结束、向用户报告结果之前都记录一次；包括模块只完成阶段目标、验证失败、尚有遗留或因证据暂停的情况。开发记录与代码/测试/相关说明在**同一次修改**中更新，不等待用户提醒。除明确获授权外，“完成开发”不等于“用户验收通过”，不能据此填写签核总表。

每条至少填写：日期与队列位置/模块、实际做了什么（对应功能点和文件/产物）、什么没做（具体遗留与禁用）、验证命令及结果/证据、风险或阻塞、下一步及是否待用户验收。若本轮无代码改动，明确标注；未执行的测试写“未运行”及原因，不能写作“通过”。涉及 ROM/IPS 等二进制变动时补前后 SHA-256 和相关 Bank/偏移；涉及当前修改器的代码、界面或操作变化时同次更新 `docs/DC修改器使用说明.md`。
