## 6. 实现注意事项与禁区

1. **禁区：D5 决策前实现/启用等级上限 61**——选项 A（复原算法，P3 逆向）/B（未复原前禁用按钮）/C（60 内完全可用；61 入口显式标注"实验性"：警告+确认）均待用户拍板，文档建议 C 仅为建议；**A 完成前 61 入口不得默认可用**（C-3：未复原前禁用该按钮或显式标注实验性）；
2. **禁区：把 60→61 简化为单字节开关**——3778 字节联动重写算法未复原，禁止猜测实现（`legacy-level-cap-result.json` 实测口径；此前"近两万"系 JSON 行数误当字节数）；
3. **禁区：F-046/F-047 回归破坏**——已对齐项只做守护（audit 脚本复跑），不再引入新写入口径；
4. **禁区：成长表半字节覆盖**——写入必须保留最后未显示半字节；高低半字节对应两等级的取序（先高后低）不得颠倒；
5. 系统文字红注三转义符（`{`+3 字节/`[`+2 字节/`\|`+1 字节直写）语义逐字复刻，注 2110 文本逐字一致；
6. 系统文字与道具说明/商店页物理偏移冲突保护维持（M10 同源）；
7. 衔接点：`tools/audit_legacy_other1_tables.py`（表用例范式）、`tools/audit_legacy_level_cap.py`（等级上限实测）、`src/fc_editor/codecs/legacy_text.py`（system 组）、M07（距离补正编号引用方）、M10（道具说明/商店对话冲突保护）。
