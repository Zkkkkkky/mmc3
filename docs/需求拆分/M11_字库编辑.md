# M11 字库编辑

> 模块编号：M11 ｜ 状态：未启动 ｜ 优先级：P2 ｜ 依赖：黄金对照流水线（P0）；M13 文字转换（共用码表） ｜ 主文档章节：4.9 / 5.7 / 11.10
> 决策依赖：无

## 1. 范围界定

本模块覆盖"字库编辑"窗口（数据菜单入口名为"文字库"，窗口标题为"字库编辑"）：16×16 字模预览网格、文字段选择、单字模修改与写入、选择字体/替换全部字体/清空本页、文字代码与地址联动显示。继承主文档 REQ-FONT-001~006。

不做什么：

- 不做字模指针/布局搬移（当前产品编解码原则：定长字模、不动指针）；E/F 显示列是 0 列别名而非独立字模，不提供独立编辑入口。
- 自动新增编码（F-060）与全字体文件协议（F-061）属参考版已有但当前未实现的能力，本期按 P2 排期补齐，实现前先补黄金对照。
- 超集功能口径：依 D1 决策（2026-09-14）保留当前产品 .dcfont 页点阵导入导出（F-S13）等增强，不构成 1:1 偏差；不得改变参考版已有控件与动线（REQ-NFR-SUPER-001/003）。

2. 文字段选择（如 `C8`）联动预览网格与文字地址；文字代码（如 `C800`）与文字地址（如 `70010`）联动显示（REQ-FONT-002/003）。

## 6. 实现注意事项与禁区

- **禁区**：E/F 列不得作为独立字模写入（会破坏 0 列别名关系）；每页行尾 4 保留字节不清空、不写入；字模必须恰好 18 字节（12×12 点阵，只用 0/1 两色）。
- 18 字节编码为三条 4x12 竖条、字节内偶数行 nibble 在前、0 为前景——与常规"1 为前景"的位图习惯相反，实现时以此为准（`dc_font.py` decode/encode 为已修正实现）。
- 写入路径保持"定长字模、不动指针"：任何情况下不得移动字库布局或改写页首字节。
- 替换全部字体/自动新增编码/全字体文件协议在黄金对照前只读或禁用（tooltip 注明原因，G3 纪律）。
- 与当前产品代码衔接：`src/fc_editor/codecs/dc_font.py`（编码/地址换算）、`src/dc_modifier/font_edit.py` 与 `legacy_tools.py`（字库编辑窗口）；窗口仅有确定按钮的动线已在现实现中保持，验收时确认。
- 保存模型例外：字库编辑窗口只有"确定"无"取消"（主文档 6.1 第 4 条例外），复刻不得擅自加取消按钮。
- **快捷键与菜单入口**：菜单项文本「文字库&(W)」与快捷键 Ctrl+W 按菜单树实证复刻；不得增删改参考版已有菜单项（REQ-NFR-SUPER-001）。
- **回归联动**：字模写入解禁后，须同步复验 M13 文字转换（码表机理联动）并重跑 M17 模板区全量审计（10.2 回归纪律）；字模变化会改变文本渲染，涉及 Mesen 实机抽查（G5）。
