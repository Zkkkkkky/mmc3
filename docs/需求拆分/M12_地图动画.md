# M12 地图动画

> 模块编号：M12 ｜ 状态：部分实现（三页读取/安全等长编辑及物理拼图/离线播放已落地；动态黄金、背景改写与新增搬移待补） ｜ 优先级：P2 ｜ 依赖：P0 黄金对照流水线（audit_legacy_modifier_ui.py 扩展）｜ 主文档章节：4.10 / 11.11

## 1. 范围界定

本模块实现参考版"地图动画"窗口（62 控件）的三页签结构与编辑能力：

- **做**：三页签（地图动画/规律/动画调用）只读展示与既有编辑能力补证；动画指令等长参数编辑（F-063）；运行规律与组图规律编辑（F-064）；调用位置更换动画编号（F-066，仅已核对完整指令序列的调用）；代码编辑(150)与动画拼图(610)两个次级对话框入口动线；按当前 ROM `$D194—$D2EF` 解释器实现实际 CHR 物理拼图、图块映射/编号/翻转与运行规律离线播放（F-069）。
- **仍待做**：背景规律写入（F-065 保持只读）；新增动画/规律搬移/名称修改（F-067 添加按钮保持禁用、F-068 待实现）；REQ-ANIM-005 的参考 EXE 单字段保存/重开黄金。未取得证据的运行时 RAM 图块和指针页保持占位或门禁。
- **超集口径**：本窗口无直接对应超集项；依 D1 决策（2026-09-14）项目既有超集能力保留、不构成 1:1 偏差，且不得改变本窗口参考版控件与动线。

## 3. 参考版界面与行为规格

**入口动线**：主窗口菜单项「地图动画&(M)」，快捷键 Ctrl+M（controls/B03_完整菜单树.json 实证；菜单随 ROM 载入出现，REQ-MW-001）。点击后弹出本窗口。

**页签结构**（三页签，控件树坐标推导+截图证实）：

| 页签 | 组成面板（控件 ID） |
|---|---|
| 地图动画 | 动画选择(130) + 动画编辑(140) 两列并排 |
| 规律 | 背景规律(580) + 运行规律(170) + 组图规律(270) 三列并排 |
| 动画调用 | 精神相关(350) + 地图武器相关(460) 两列并排 |

**各面板控件**：动画选择=列表(110，`[01]001: 坠机爆炸` 格式)+添加(120)+动画名称(290+280)；动画编辑=指令列表(340，反汇编行如 `000: 调用颜色（物理）：颜色三字节:30 38 28`)+代码编辑(150)；背景规律=列表(530)+名称(560+570)+代码(540+550)；运行规律=列表(160)+添加(320)+名称(200+210)+代码(180+190，`09 FB 0A FC …`)；组图规律=列表(220)+添加(330)+名称(250+260)+代码(230+240)+预览图库(590+600，`[08]008：82010`)+动画拼图(610)+X/Y(620/640+630/650，UpDown)；精神相关=列表(360)+精神选择(370)+设置(380)+动画调用(390+400)；地图武器相关=列表(410)+选择(420)+设置(430)+动画调用×4(440/450、470/480、490/500、510/520)。

## 4. 数据与写入规格

**动画六表**（当前实现 `src/fc_editor/codecs/animation.py` 的表定义，E5 现状；ROM 落点依 REQ-ANIM-005 为 candidate，未做差分验证）：

| 表 | 记录长 | 条目数上限 |
|---|---|---|
| map（地图动画） | 0x28 | 153 |
| ally（我方） | 0x22 | 256 |
| enemy（敌方） | 0x20 | 256 |
| background（背景规律） | 0x0A | 106 |
| movement（运行规律） | 0x18 | 157 |
| sprite（组图规律） | 0x18 | 249 |

- 等长约束：动画指令与规律记录均为定长结构，**仅支持等长编辑**；编辑器必须按记录长校验并拒绝超长输入（参照 5.6 等长替换纪律）。
- 调用绑定（F-066）：精神/地图武器调用面板把动画编号写入绑定字段；事件上下文未验证的调用保持只读。
- candidate 状态字段：动画指令内部参数语义（等待帧/颜色三字节/物体编号/坐标/音乐代码等）以反汇编行展示口径为准，写入落点全部 candidate——黄金对照通过一项开放一项。
- 背景规律区与"添加"按钮目标区：只读/禁用，无写入规格。
- 条目容量：各表条目数上限如上表；当前已用条目数以实际 ROM 加载为准，新增（若解禁）不得超过上限。
- 物理拼图协议：当前 ROM Bank `$3E` 的 `$D194—$D2EF` 直接证明组图记录为“有符号 X、有符号 Y、首图块、逐块命令…`FF`”；命令的 `$C0` 为水平/垂直翻转，低两位为调色板，`$20/$10/$08/$04` 控制换图块及后继 X/Y 步进。249/249 槽均完整终止。
- 播放协议：按 `$E8CC—EA34` 执行组图帧序列；81 项运行规律被调用上下文唯一识别为帧序列，79 项可离线终止或识别稳定循环。`$12` 读取运行时循环次数、`$21` 切换运行时指针页，离线预览明确门禁。

## 6. 实现注意事项与禁区

1. **等长红线**：所有动画/规律编辑按定长记录校验；超长输入整体拒绝（REQ-NFR-STAB-002）。
2. **candidate 保持原值**：未通过黄金对照的参数在 UI 中只读展示，不提供编辑入口。
3. **背景规律/添加按钮维持现状**：F-065 只读、F-067 禁用；解禁必须先有容量/安全性证据并回写主文档（G3）。
4. **次级对话框**：动画拼图(610)→物理拼图对话框；代码编辑(150)→"请输入动画指针"对话框——按探针截图（D5 系列）复刻入口动线。物理拼图的图库地址、00/80 起点、图块编号、整图翻转和确定/取消均保留，离线播放置于同一窗口且只影响预览。
5. **保存模型**：确定(310)提交内存 ROM 缓冲、取消(300)丢弃（6.1 两级提交）；本窗口属子窗口草稿层。
6. **衔接点**：`src/fc_editor/codecs/animation.py`（六表定义）、`animation_editor.py` L264（添加禁用）、L434-435（调用更换限制）——实现时以上述口径核对现状再动。
7. **快捷键与菜单入口**：菜单项文本「地图动画&(M)」与快捷键 Ctrl+M 按菜单树实证复刻；不得增删改参考版已有菜单项（REQ-NFR-SUPER-001）。
8. **回归联动**：本模块任一写入能力解禁后，须重跑 M17 模板区全量审计（10.2 回归纪律）。
