## 1. 范围界定

本模块覆盖数据库窗口"机体修改"页签（4.3 全部）：机体选择列表（含添加/查找）、机体图片区（预览/上传/清除/导图偏移/压缩上传/机体拼图/碎片拼图/显示复选/三色×2/类型/图片地址×3/图标）、基本设置（名称/适应地形/变形）、机体属性（11 数值字段+特殊技能）、机体武器（2 槽+转到武器跳转），及次级对话框（机体拼图/碎片拼图/机体图标设置）。继承 REQ-DB-UNIT-001~009、REQ-DATA-UNIT-001/002。

不做：武器修改页本体（M07）；其他五页签与窗口壳/共享底部（数据库窗口公共部分，各页模块共同引用）；旧版五 BMP 批量导出协议（M18）。机体大小类型转换已实现安全迁移，但 F-027 的参考版写入级差分仍归本模块完成。

超集功能口径（依 D1 决策保留、不构成 1:1 偏差、不参与本模块 1:1 验收）：128×128 战斗预览按游戏图层合成（F-021）；目录右键复制/粘贴/还原（F-S14）；数据库窗口缩放/缓存复用（F-S16）；原槽内直接改名（F-016 的先行实现）。不得增删/改名参考版已有控件与动线（REQ-NFR-SUPER-001/003）。

## 6. 实现注意事项与禁区

1. **禁区：保留字节 0x0B 写入**——基准 ROM 全部唯一记录均为 00，未证实用途前只读（5.2）；
2. **禁区：candidate 字段未过黄金对照前保持原值原则**——通过对照后逐步解禁（REQ-DATA-UNIT-001）；
3. **容量边界：F-026 的“添加”可点击查看 `$01—$FF` 已占满的容量诊断，但操作保持零写入**；不得伪造第 256 个 ID，替换需求应选择既有 ID 后使用复制/粘贴或导入；上传、清除、图标绑定和大小类型转换均已完成产品侧复验，参考版动作按 18 项黄金与 7 项明确非黄金结论登记，不以破坏性或非持久化参考行为扩大写入范围；
4. **禁区：跨 ID 联动覆盖**——机体属性和名称都按逻辑 ID 独立编辑；当前 ROM 中重复的属性/名称指针只是压缩或复制结果。普通属性表单、复制、导入、还原和高级 16 字节写入必须自动拆分目标 ID，不弹联动修改确认且不得改变其他 ID；
5. 机体大小类型转换（F-027）已完成 14,066 条确定性迁移的写入级差分验证；
6. 红字警示（控件 2500，"方向武器死机警告"）文本逐字一致（4.3 验收标准）；
7. 衔接点：`src/fc_editor/models.py`（UNIT_FIELDS 字段映射）、`src/dc_modifier/legacy_windows.py`（外壳/禁用）、M07（转到武器跳转目标）、M18（导出机体共用图形协议）。
