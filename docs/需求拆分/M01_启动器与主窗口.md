> 模块编号：M01 ｜ 状态：部分实现（实现侧离屏回归已开展；现场动线/黄金对照未签核） ｜ 优先级：P1（打开/保存两级提交签核） ｜ 依赖：M00（黄金对照流水线） ｜ 主文档章节：4.1 / 4.2 / 6.1 / 6.2 / 11.1

## 1. 范围界定

本模块覆盖：启动器窗口（作者信息+进入按钮，不参考截图）；主窗口壳层（菜单栏 14 项、未载入/载入两态、打开/保存动线、两级提交保存模型）；三页签工作区容器与共享关卡选择列表（页签内容分别归 M02/M03/M04）；标题栏 ROM 路径追加规则。

不做：三页签内部功能（M02/M03/M04）；数据库等"数据"菜单子窗口（M05—M18）；"导出机体/导出头像"动线细节（M18）。

超集功能口径（依 D1 决策保留、不构成 1:1 偏差、不参与本模块 1:1 验收）：未保存提示/派生 ROM 输出/覆盖前时间戳备份（F-S15，REQ-BEH-SUPER-001）；"扩展功能""工程"超集菜单组及工程快捷键——.dcmod 工程系统（F-S04）、撤销/重做 Ctrl+Alt+Z/Y（F-S05）、F7 变更与验证完整检查（F-S06）、IPS/构建报告 Ctrl+B 一键构建（F-S07）、完整 ROM 数据读取·七类全表+全量 HEX（F-S09，"扩展功能"菜单入口）、扩展容量规划·地图/机体/剧情分区（F-S10）（主文档 11.18）。约束：参考版已有的控件、菜单项与动线不得因超集功能而增删、改名或改变触发方式（REQ-NFR-SUPER-001）。

## 4. 数据与写入规格

本模块无直接 ROM 可写字段（打开/保存为文件级操作）。写入语义约束：

| 事项 | 规格 | 状态 |
|---|---|---|
| 保存方式 | 直接写回当前 ROM 文件，无确认弹窗、无备份（REQ-BEH-002） | confirmed（动线规格+审计脚本实测） |
| 保存往返 | 保存后重开，显示值必须等于已保存值（黄金对照第 4 步语义） | confirmed（#19 模板区已验证） |
| 标题追加 | 载入后 `SRW2扩容版修改器V1.0：<ROM绝对路径>`（全角冒号） | confirmed（控件树 B02） |
| 归一化排除 | 保存不得执行 6 偏移 C9 02→D8 47 归一化（REQ-BEH-EX-001） | confirmed |
| 超集保存行为 | 派生 ROM 输出/未保存询问/时间戳备份保留（REQ-BEH-SUPER-001） | 超集口径（D1） |

实现侧依 D1 保留超集安全路径：第一次“文件→保存”选择派生 ROM；之后直接保存到该派生文件、不再选名；覆盖前建立唯一时间戳 `.bak`，当前载入 ROM（包括可写工作副本）不原地覆盖，`references/` 始终只读。参考版“直接写回/无自动备份”是黄金行为基线，但不作为移除 D1 的依据；C-5 仍按双环境复测，不能据派生保存往返撤销 NEG-3 或签核参考动线。

## 6. 实现注意事项与禁区

1. **禁区：保存加确认弹窗/自动备份**（REQ-BEH-002，NEG-2/NEG-3）——但超集安全行为（未保存询问/派生 ROM/时间戳备份）依 D1 保留（REQ-BEH-SUPER-001），二者并存时不得干扰参考版动线执行结果（REQ-NFR-SUPER-003）；
2. **禁区：未载入时显示"数据"菜单**（REQ-MW-001）；
3. **禁区：标题半角冒号或省略路径**（REQ-MW-003）；
4. 启动器点击"进入修改器"必须销毁窗口（HWND 失效，探针需重新枚举）；
5. C-5 处理原则：探针环境按否定证据处理（不实现自动备份）；若 #5 用例复现则按参考版目录格式实现并撤销 NEG-3（主文档 5.11）；
6. 衔接点：`src/dc_modifier/` 主窗口与启动器代码（启动器保持"作者署名+进入按钮"精简布局，作者署名改为 `断月残心`，不扩展外部链接/QQ 群信息区、不参考截图）。
