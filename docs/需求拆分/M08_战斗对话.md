## 1. 范围界定

本模块覆盖数据库窗口"战斗对话"页签（4.6 全部）：对话段选择（ComboBox+ListBox）、对话行列表、按列表/按内容子页签（CPageControl 2570）、文字编辑区；对话段文本的读取/编辑/保存（等长容量内）；F8 随机对话分支的间接寻址语义。继承 REQ-DB-BDLG-001~003、REQ-DATA-TXT-001。

不做：人物修改页台词绑定按钮（M06——其"编辑战斗对话"弹窗动线引用本模块数据）；剧情文本八组（M13 文字转换/剧情范畴——本模块只管 battle 四组）；系统文字（M09）；道具说明（M10）；字库（M11）。

超集功能口径（依 D1 决策保留、不构成 1:1 偏差、不参与本模块 1:1 验收）：控制 Token 与别名无损往返（F-044 先行实现）；随机台词分支单独呈现。不得增删/改名参考版已有控件与动线（REQ-NFR-SUPER-001/003）。

## 6. 实现注意事项与禁区

1. **禁区：文本池越界与重排**——只用原容量，越界一律拒绝（REQ-DATA-TXT-001；F-045 未实现前不搬移）；
2. **禁区：Token 位改写**——控制 Token/别名无损保留（F-044），编辑不得破坏非可编辑 Token 字节；
3. F8 间接寻址条目的编辑目标为指针指向的实际条目，不得把 F8 头本身当文本改写；
4. 转义约定五符号与参考版逐字一致（REQ-DB-BDLG-002）；
5. 子页签语义（按列表/按内容）【推断待验证】，以控件树/黄金对照复核；
6. 编辑区默认内容形态与参考版一致（如参考版编辑区呈现 `[F000：_{FCFFFF_】` 形式的 Token 混合文本，控件枚举实测）；
7. 列表条目格式含人物名与文本（REQ-DB-BDLG-001），呈现顺序与参考版一致；
8. 文本缩短后恢复用例必须双向验证（缩短→保存→改回→保存，差分为空）；
9. 衔接点：`src/fc_editor/codecs/legacy_text.py`（TEXT_GROUPS/F8 分支）、M06（台词绑定写回人物记录）、M13（文字转换共用码表）、M09（系统文字组）、M10（道具说明组——系统文字页与商店页物理偏移冲突保护同源）。
