> 模块编号：M18 ｜ 状态：未启动 ｜ 优先级：P2 ｜ 依赖：P0 黄金对照流水线（像素比对工具，G6）；D2（导出头像处理）｜ 主文档章节：4.16 / 5.8 / 11.17 / 9.2（D2）
> 决策依赖：**D2（待决策：参考版"导出头像"不可触发如何处理）**——选项 A 如实复刻（菜单项存在、点击无任何效果）/ B 菜单置灰禁用，说明标注"参考版不可触发" / C 按推测的 BMP 导出协议实现【推断待验证】。建议：先补触发条件研究（是否依赖特定 ROM 状态/前置操作，12.B2 用户配合 5 分钟）；仍无法复现则取 B。**禁止 C——未经验证的导出违背 3.4 纪律**。未决策前导出头像不实现任何导出行为。

## 1. 范围界定

本模块实现参考版"导出机体"批量导出与"导出头像"两项功能：

- **做**：导出机体菜单动线（数据→导出机体 Ctrl+F，命令 20017）与系统通用保存对话框（REQ-EXP-001）；按五 BMP 协议批量导出全部机体（REQ-EXP-002）；产物与参考版逐像素一致（REQ-EXP-003，G6 验收）；头像两图 BMP 导出的既有实现补动态黄金对照（F-097）；导出头像菜单项按 D2 决策落地。
- **不做**：按推测协议实现导出头像导出行为（C 选项禁止）；机体组合像素规则未经黄金样本确认前不宣称对齐；不改动超集 .dcunit 机体包（F-S08，依 D1 保留）。
- **边界**：导出读取的是当前内存 ROM 缓冲中的图形数据（与参考版一致）；全程不写 ROM、不弹确定/取消——与两级提交模型（6.1）无关。
- **超集口径**：当前产品 .dcunit 包导入/导出（F-S08）与头像 BMP 导出（F-097）均为超集/新协议形态——依 D1 决策（2026-09-14）保留、不构成 1:1 偏差，但参考版旧版协议导出必须另行实现，不得以 .dcunit 替代宣称完成。

当前产品现状（8.1 #15"缺失"/#16"部分"）：旧版协议导出机体基本从零开始（已有确定性 BMP 编码器与目录/命名/尺寸框架，菜单当前接 .dcunit）；F-097 卡在参考版不可触发（NEG-5）导致无法采集动态黄金样本——D2 决策是前置。本模块排期在 P0 黄金对照流水线（G6 像素比对工具）就绪之后启动；协议细节以用户既有导出样本（12.B3，若用户可提供）优先提速。

## 3. 参考版界面与行为规格

**入口动线**（controls/B03_完整菜单树.json 实证）：

- 导出机体：数据菜单「导出机体&(P)」，快捷键 Ctrl+F（命令 20017）。
- 导出头像：数据菜单「导出头像&(L)」，快捷键 Ctrl+L（命令 20018）。

**导出机体操作动线**：数据→导出机体（Ctrl+F）→ 弹出系统通用保存对话框（`#32770`，保存&S/取消）→ 选定根目录 → 参考版按 ID 1..N 批量导出全部机体。另据差异矩阵（E4）：机体列表右键入口仅导出当前项、头像入口仅导出当前人物【推断待验证：右键/头像入口在探针轮次未复现，需黄金对照补证】。

**导出头像否定证据 NEG-5**：菜单项触发后无任何窗口创建（探针多轮触发+40/90/300s 轮询不可复现）——参考版该功能不可触发；处理方式见 D2。

**保存对话框**（D11，force-show 方案捕获）：51 控件系统通用 `#32770` 保存对话框（保存&S/取消）——参考版未提供自定义控件，全部为系统对话框控件（文件名编辑框、目录树、保存类型下拉等均为 Windows 系统控件，复刻版直接接系统对话框，无需自绘复刻）。对话框默认文件名/默认目录参数【待黄金对照补证——force-show 捕获的是空参数形态】。

**导出协议**（研究文档 E4 级，尚未逐字节比对，G6 指标要求补证）：

| 项 | 值 |
|---|---|
| 目录命名 | `<十进制ID>：<名称>`（全角冒号） |
| 机体五图 | `[效果]`、`[机体]`、`[碎片]`、`[图标1]`、`[图标2]` |
| 头像两图 | `[背面]`、`[正面]` |
| 尺寸 | 效果/机体/碎片 128x128；图标 16x16；头像 32x32 |
| 文件格式 | 24-bit BI_RGB、BGR、bottom-up BMP |
| 命名敏感点 | 目录名全角冒号「：」；文件名方括号为半角 [效果] 等 |

**需求条目**：REQ-EXP-001（菜单与快捷键动线一致；保存对话框为系统通用对话框）、REQ-EXP-002（落盘目录与文件名按上表协议；BMP 编码参数一致）、REQ-EXP-003（导出产物与参考版导出产物**逐像素一致**，G6）、REQ-EXP-004（导出头像在参考版不可触发——见 NEG-5 与 D2）。

## 4. 数据与写入规格

- **只读导出**：本模块不写 ROM——全部产物为磁盘 BMP 文件；无确定/取消（菜单命令直接触发保存对话框）。
- **BMP 编码参数**（E4 级，待 G6 逐像素验证后升级 confirmed）：24-bit BI_RGB、BGR 字节序、bottom-up 行序；尺寸按协议表。
- **像素组装规则**：机体战斗图 128x128 由 8x8/7x9/9x7/10x6 拼图协议组装（4.5 机体拼图尺寸按钮口径，5.8）；拼图代码为十六进制串（如 `F3 F8 00 01 …`）——**组合像素规则未经黄金样本确认前为 candidate**，不得宣称对齐。
- **拼图尺寸口径**：8x8（标准）、7x9/9x7（窄高/宽矮变体）、10x6（宽扁变体）四尺寸对应参考版机体编辑的拼图尺寸按钮；导出与 4.5 机体编辑共享同一拼装实现，不得另造第二套口径。
- **头像数据源**：头像 32x32 点阵自人物头像数据只读导出；旧版协议的调色板/像素排布细节【待动态黄金样本——受 NEG-5 阻塞，随 D2 决策解锁】。
- **导出头像（D2）**：参考版不可触发（NEG-5）；D2 未决策前复刻版不得实现任何导出行为；当前产品既有头像 BMP 导出属新协议（F-097），与旧版协议一致性待动态对照。
- **命名细节**：目录名全角冒号（与 C-4/REQ-SAVE-005 同类全半角敏感点）；`<十进制ID>` 的进制形态（是否补零）【待黄金样本确认】。
- **图标语义**：[图标1]/[图标2]（16x16）为机体图标两种形态【具体语义（帧/用途）待黄金样本确认】；[效果]/[机体]/[碎片]（128x128）为战斗图三形态。

## 6. 实现注意事项与禁区

1. **D2 未决策不实现**：导出头像不得实现任何导出行为；C 选项（按推测协议实现）在任何情况下禁止（3.4 纪律）；菜单项存在性按 A/B 选项决策结果落地。
2. **G6 一票否决**：像素不一致即未完成——不得以"视觉相似"替代逐像素比对；比对工具纳入 P0 流水线。
3. **协议 candidate 纪律**：目录命名/文件名/尺寸/BMP 参数在黄金样本比对通过前均按 candidate 处理，UI 不宣称"旧版协议已支持"。
4. **超集并存**：.dcunit 机体包导入/导出（F-S08）保留且默认可见（D1）；旧版协议导出为独立菜单动线（Ctrl+F 同一入口接旧协议），不得移除或改名参考版菜单项（REQ-NFR-SUPER-001）。
5. **全角冒号**：目录名 `：` 为全角——编码/文件系统层面逐字复刻（Windows 文件名允许全角冒号，半角冒号非法，注意区分）。
6. **快捷键**：Ctrl+F（导出机体 20017）/Ctrl+L（导出头像 20018）按菜单树与命令 ID 实证复刻。
7. **衔接点**：`src/dc_modifier/` 既有 .dcunit 导出与头像 BMP 导出（超集/新协议）——旧协议实现为新增路径，不动超集入口；像素组装复用 4.5 机体拼图口径（8x8/7x9/9x7/10x6）。
8. **回归联动**：本模块不写 ROM；完成后与其他模块一样触发 M17 模板区回归重跑。
9. **产物基准库**：参考版导出产物全集存档至 output/build/legacy-diff-audit/（G6 比对基准库）；基准库一旦建立不得覆盖，只追加。
10. **ID 范围口径**：批量导出按 ID 1..N；N 与机体总数（指针表 0x4876F 共 0x100 项，5.2）的关系【待样本确认】，不得提前固化。
11. **批量规模**：全量导出按机体总数（≤0x100）逐机体五图落盘，须顺序导出、及时释放句柄（一次性全载入内存的形态禁止）；单个机体导出失败不得中断整批，以失败清单记录收尾【参考版失败行为待实测确认】。
