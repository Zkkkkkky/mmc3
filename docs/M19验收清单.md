## 2. 编号验收步骤

| # | 步骤 | 预期结果 | 通过 | 证据 |
|---|---|---|---|---|
| 1 | 打开“数据 → 地图动画”，选择 `$13` 或 `$14`，点击“字幕内容（制作信息与出演名单）” | 出现两个编辑区、两个预览、三类计数和恢复/确定/取消按钮；其他动画不显示该入口 | | |
| 2 | 不修改直接确定，再查看变更 | ROM 零字节变化 | | |
| 3 | 在制作信息中缩短一行并确定 | 只变化 `0x07BCA9—0x07BCF4`，控制前缀及后续数据不变 | | |
| 4 | 字幕窗口确定后取消地图动画窗口 | 字幕和动画均不写入；重新操作并确定地图动画后，撤销/重做一次恢复/应用全部内容 | | |
| 5 | 输入超出 75/109 字节、3/11 行或 18/10 格宽度的内容 | 对应计数变为警示，确定禁用，ROM 不变 | | |
| 6 | 删除出演名单中的“勒”并确定 | `C9F3` 全 ROM 引用由 1 降为 0；字库检测后可安全回收“勒” | | |
| 7 | 点“恢复打开 ROM 时的内容” | 只恢复窗口草稿，确定前工程不变 | | |
| 8 | 保存派生 ROM并重开该窗口 | 修改内容、分行和对齐保持一致 | | |
| 9 | 在模拟器中触发制作信息/出演画面 | 显示修改后的内容，后续画面正常；记录截图或录像 | | |
| 10 | 修改字幕并在字幕子窗口确定，不关闭地图动画窗口即打开预览 | 快速预览与游戏内真实预览均使用暂存字幕；关闭预览后工程仍无新撤销记录 | | |
