# 旧修改器功能保全黄金门禁

## 1. 目标

新修改器的最低交付标准是完整保留旧修改器已经证实存在的功能，再叠加性能、界面、事务、撤销、预览和容量展示优化。用户不负责逐项发现被删功能；缺口排查和恢复属于开发门禁。

## 3. 强制规则

1. 参考版存在的入口、字段、自然语言、操作顺序、子窗口和结果不得删除、隐藏、禁用、合并或改义。
2. 优化必须是加法：可以更快、更紧凑、更清楚、可撤销，但不能改变旧功能最终可达性和结果。
3. 字段覆盖和界面相似都不等于功能完整；右键、双击、导入/导出、复制/粘贴、清除、插入、删除、保存、取消均单列为动作。
4. 未取得证据的功能先保留、再取证；不得把“不确定”变成“删除”。
5. 任何差异必须记录证据、影响和用户对该具体差异的明确授权。没有授权即按旧版恢复。
6. 每次模块改动都要做改前/改后可达性对照，并验证保存重开、取消回滚和撤销/重做。

## 5. 每模块放行条件

- 参考控件签名无无解释缺失；
- 参考动作清单逐项可达；
- 自然语言和十六进制/十进制显示遵循参考版；
- 保存结果通过已有黄金差分或明确保持门禁；
- 取消、撤销、重做和重开不破坏数据；
- 优化前后功能数不减少；
- 用户说明、需求状态和开发记录同步；
- 只有用户本人可以填写最终验收结论。
