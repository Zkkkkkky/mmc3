# 项目文档

`docs/` 是项目的用户文档、维护文档和研究说明入口：

- [使用说明](DC修改器使用说明.md)：面向修改器使用者的完整操作步骤、快捷键、校验与限制。
- [设计与实现方案](DC修改器设计与实现方案.md)：当前修改器的分层架构、功能方案与扩展边界。
- [交接文档](交接文档.md)：ROM Bank、构建身份、音频实现和模拟器验证要求。
- [提交记录](提交记录.md)：历次开发内容、影响范围与当时的验证结果；这是历史记录，旧路径与旧命令不做追溯性改写。
- [`research/`](research/)：整理后的逆向研究笔记和旧修改器复刻规格。
- [`images/dc_modifier/`](images/dc_modifier/)：Markdown 使用说明所引用的界面截图。
- [`archive/`](archive/)：已经淘汰的 ROM 与音频方案报告，仅作技术参考。

可编辑文档保存在这里；由脚本生成的 PDF 交付件写入 [`output/pdf/`](../output/pdf/)，不与文档源文件混放。

项目源码位于 [`src/`](../src/)，维护脚本位于 [`tools/`](../tools/)，测试位于 [`tests/`](../tests/)。原始 ROM、旧修改器、历史音频和模拟器状态属于只读输入，边界见 [`references/README.md`](../references/README.md)；构建 ROM、补丁、报告、映射表和验证产物统一写入 [`output/`](../output/)。
