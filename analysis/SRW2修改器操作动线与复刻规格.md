# SRW2 修改器操作动线与复刻规格

> 目标：为一比一复刻 `references/legacy_modifier/SRW2_patched.exe` 提供导航、窗口、状态和交互依据。
>
> 验证环境：`SRW2_patched.exe` + `FC模拟器/DC_kuorong.nes`。界面截图位于同目录的 `SRW2修改器界面截图/`。
>
> 可信度标记：**已验证**表示通过实际打开软件、查看窗口或控件确认；**待实测**表示仅从控件名称和界面结构推断，复刻行为前仍需做输入—保存—ROM 差异实验。

## 1. 总体操作动线

```text
启动 SRW2_patched.exe
  └─ 启动页“进入修改器”
      └─ 空白主窗口
          └─ 文件 → 打开（Ctrl+O）
              └─ 选择兼容 NES ROM
                  ├─ 主窗口：战场地图
                  ├─ 主窗口：初始配置
                  ├─ 主窗口：商店事件
                  └─ 数据菜单
                      ├─ 数据库
                      ├─ 文字库
                      ├─ 地图动画
                      ├─ 文字转换
                      ├─ 剧情事件
                      ├─ 导出机体
                      ├─ 导出头像
                      ├─ 属性计算器
                      ├─ 存档修改器
                      └─ 其他

编辑完成
  ├─ 子窗口“确定”：提交当前窗口数据到已加载 ROM 缓冲区
  ├─ 子窗口“取消”：放弃当前窗口未确认的编辑并关闭
  └─ 文件 → 保存（Ctrl+S）：将 ROM 缓冲区写回文件
```

## 2. 全局状态模型

复刻时建议把状态明确分为四层：

| 状态层 | 内容 | 生命周期 |
|---|---|---|
| 启动器状态 | 启动页、资料链接、进入按钮 | 进入主程序前 |
| ROM 会话 | 当前 ROM 路径、ROM 字节、是否已修改 | 打开 ROM 后到退出 |
| 页面选择 | 当前关卡、当前记录、当前页签、当前图块/对象 | ROM 会话期间 |
| 编辑草稿 | 子窗口中尚未按“确定”的字段值 | 当前子窗口期间 |

窗口标题必须反映状态：

- 未载入：`SRW2扩容版修改器V1.0`
- 已载入：`SRW2扩容版修改器V1.0：<ROM 绝对路径>`

没有载入 ROM 时，只显示“文件、帮助”菜单和空白工作区；载入成功后才出现“数据”菜单与三张主页面。加载不兼容布局时原程序可能出现黑色绘图区，因此复刻版应改为明确的格式校验错误，不能静默显示黑屏。

## 3. 启动页

截图参考：无单独归档截图；启动页在实测中确认。

### 3.1 控件与动线

| 控件 | 动作 |
|---|---|
| 第二次机器人大战百度贴吧 | 打开外部资料链接 |
| 第二次机器人大战公共网盘 | 打开外部资料链接 |
| 第二次机器人大战资料集 | 打开资料集 |
| 修改器更新查看 | 打开更新网盘链接 |
| 进入修改器 | 关闭/隐藏启动页，创建主程序窗口 |

### 3.2 复刻要求

- 启动页尺寸固定、不可最大化。
- “进入修改器”是主要动作，位于底部居中。
- 外部链接属于附属功能；一比一视觉复刻时保留位置和文字，实际 URL 需另行核实。

## 4. 主窗口和文件菜单

### 4.1 文件菜单

| 菜单项 | 快捷键 | 前置条件 | 结果 |
|---|---:|---|---|
| 打开 | Ctrl+O | 无 | 打开 `*.nes` 文件选择框；成功后初始化整个 ROM 会话 |
| 保存 | Ctrl+S | 已载入 ROM | 将当前内存数据写回 ROM；原程序存在自动备份行为 |
| 退出 | Ctrl+X | 无 | 关闭修改器；有未保存修改时是否提示需实测 |

### 4.2 主窗口共享控件

- 左下“关卡选择”是三张主页面的共享主记录选择器。
- 选择关卡后，地图、初始配置、商店事件以及剧情窗口均应切换到同一关卡数据。
- 右下状态区显示地图光标 `X坐标`、`Y坐标`。
- 三个顶部页签不创建新窗口，只替换左侧编辑面板；地图画布仍保持在右侧。

## 5. 主页面动线

### 5.1 战场地图

截图：[01_战场地图.png](SRW2修改器界面截图/01_战场地图.png)

```text
选择关卡
  → 加载关卡地图、宽高、标题图和图块库
  → 在“位图选择”中选择图块
  → 设置左键/右键当前图块
  → 在右侧地图画布点击或拖动绘制
  → 可切换图库或进入“编辑图块属性”
  → 文件 → 保存
```

界面要素：

- 图块预览区：当前图库的一组图块。
- “位图选择”下拉框：显示图库编号及 ROM 地址。
- 左键、右键：各自保存一个绘图图块，支持不同鼠标键快速绘制。
- “图库选择”下拉框：切换图块来源。
- “编辑图块属性”：进入图块属性编辑流程。
- 地图高度、地图宽度：当前截图中只读。
- 标题预览：显示当前关卡标题字模。
- 地图画布：按地图尺寸绘制；移动指针实时更新底部坐标。

待实测：单击/拖动的连续绘制规则、右键是否绘制还是取样、撤销机制、图块属性字段及保存边界。

### 5.2 初始配置

截图：[02_初始配置.png](SRW2修改器界面截图/02_初始配置.png)

```text
选择关卡
  → 切换“初始配置”
  → 显示 3 组机体图标页及各自地址
  → 在地图/配置对象上完成初始单位设置（具体触发方式待实测）
  → 文件 → 保存
```

已确认界面显示三个图标地址下拉框和三组 16×16 风格机体图标图集。该页与右侧地图共同构成初始部署编辑器，但对象放置、阵营切换、人物绑定及删除手势需进一步做 ROM 差异实验。

### 5.3 商店事件

截图：[03_商店事件.png](SRW2修改器界面截图/03_商店事件.png)

```text
选择关卡
  → 切换“商店事件”
  → 左侧加载该关商店/事件记录
  → 选择或编辑记录
  → 在右侧地图定位事件坐标
  → 文件 → 保存
```

第 1 关左侧为空属于该关没有对应记录，不是加载失败。复刻时应区分“空记录”和“读取错误”：空记录显示白色空列表，读取错误显示明确提示。

## 7. 数据库

截图：[04_数据库.png](SRW2修改器界面截图/04_数据库.png)

### 7.1 一级页签

1. 机体修改
2. 人物修改
3. 武器修改
4. 战斗对话
5. 其他修改1
6. 其他修改2

共同模式：

```text
打开数据库
  → 切换数据类别页签
  → 左侧选择记录
  → 右侧加载字段和图像
  → 修改字段/替换资源
  → “确定”提交全部数据库修改
  └─ “取消”关闭并放弃未确认内容
```

### 7.2 机体修改页

- 左侧：机体记录列表，底部“添加”；窗口底部有查找上一个/下一个。
- 机体图片：
  - 上传机体、清除机体；
  - 上传碎片、清除碎片；
  - 导图偏移；
  - 调换图库、压缩上传；
  - 机体拼图、碎片拼图；
  - 显示机体、显示碎片。
- 机体图标：上传图标、更改图标。
- 配色：机体三色、碎片三色。
- 元数据：机体类型、图片地址、碎片地址。
- 基本设置：机体名称、适应地形、变形。
- 机体属性：机动、强度、防御、速度、HP、基础经验、基础金钱、特殊技能及各成长值。
- 机体武器：武器 1、武器 2，以及“转到武器”跳转按钮。

### 7.3 复刻数据库时必须保持的交互

- 选择列表项立即刷新右侧所有字段。
- “转到武器”切换到武器页并自动选中关联武器。
- 上传/清除是资源级动作；实际写入应延迟到“确定”或至少支持取消回滚。
- 地址字段用于观察和定位，是否允许直接编辑需实测。
- 其他五页的完整字段、范围、联动规则需逐页补做控件清单；当前资料足以复刻导航和外壳，不足以保证数据语义一比一。

## 8. 文字库

截图：[05_文字库.png](SRW2修改器界面截图/05_文字库.png)

```text
打开文字库

  → 预览对应字模
  → 修改单字 / 选择字体批量替换 / 清空本页
```

- 字段选择下拉框。
- 字形修改输入区和“写入文字”。
- “选择字体”“替换全部字体”“清空本页”。

## 9. 地图动画

截图：[06_地图动画.png](SRW2修改器界面截图/06_地图动画.png)

一级页签：

1. 地图动画
2. 规律
3. 动画调用

默认页动线：

```text
左侧选择动画
  → 右侧显示逐条动画指令
  → “代码编辑”修改指令
  → 可“添加”动画并编辑名称
```

动画指令区以序号展示解析后的语义，例如图库切换、调色、等待、创建物体、运行规律、播放音乐和动画结束。复刻时应采用“原始字节 + 语义化指令模型”，以保证未知指令能够无损往返。

## 10. 文字转换

截图：[07_文字转换.png](SRW2修改器界面截图/07_文字转换.png)

- 上框输入文字，下框输出代码；“文字转代码”执行编码。

## 12. 导出机体与导出头像

这两个菜单项进入文件保存流程：

- 导出机体：导出当前/所选机体资源，快捷键 Ctrl+F。
- 导出头像：导出头像资源，快捷键 Ctrl+L。

当前未执行真正导出，以免产生不必要文件。待实测项目：导出范围、文件格式、命名规则、是否包含调色板和元数据。

## 13. 属性计算器

截图：[09_属性计算器.png](SRW2修改器界面截图/09_属性计算器.png)

```text
分别配置敌方与我方
  → 选择人物、机体、武器、等级
  → 输入/加载强度、防御、速度、HP、命中、射程等
```

## 14. 存档修改器

截图：[10_存档修改器.png](SRW2修改器界面截图/10_存档修改器.png)

```text
打开存档文件
  → 选择存档槽
  → 读取存档
  → 选择关卡
  → 编辑上下两组单位表
  → 写入存档
  → 保存存档文件
```

上表包含 EXP，下表包含金钱；共同字段包括序号、人物、机体、等级、机动、强度、防御、速度、HP、双击速度。窗口刚打开且未载入存档时显示空表。

这里存在两阶段写入：“写入存档”把表格值写入内存中的存档对象，“保存存档文件”才落盘。复刻时必须保留这个区分，并在关闭未保存文件时提示。

## 15. 其他

截图：[11_其他.png](SRW2修改器界面截图/11_其他.png)

该窗口集中编辑全局公式和初始机体：

- 双击公式：3 个数值。
- 伤害计算公式：5 个数值。
- 命中计算公式：1 个数值。
- 道具相关修改：超合金 Z 防御增加等 12 个数值。
- 初始机体：5 行、左右各一个机体下拉框，共 10 个初始机体槽。
- “确定”提交，“取消”放弃。

公式字段的精确数学含义、取值范围、溢出规则和 ROM 地址必须通过差异实验确认。

## 16. 一比一复刻的窗口规则

- 主窗口：可最大化，菜单栏固定在顶部，三页签位于菜单下方。
- 数据库、地图动画、剧情事件、属性计算器、存档修改器：独立窗口；原程序部分窗口会覆盖或禁用主窗口。
- 小工具（文字转换、其他）：居中覆盖主窗口。
- 子窗口统一使用右下角“确定/取消”，确认后返回主窗口。
- 选择记录时立即刷新预览，但不应立即写盘。
- 最终 ROM 落盘入口只有主窗口“文件 → 保存”。
- 文件型工具（存档、导出）拥有自己的打开/保存生命周期，不与 ROM 保存混淆。

## 17. 复刻实施顺序

1. 先实现启动页、空白主窗口、打开/保存 ROM 和标题状态。
2. 建立统一的 ROM 会话、脏状态、命令历史和确认/取消事务模型。
3. 完成主窗口框架、关卡共享选择器和三个页签。
4. 完成数据库的导航外壳和“记录列表 → 详情 → 确定/取消”通用组件。
5. 接入文字库、剧情事件和地图动画的语义化指令编辑器。
6. 接入文字转换、属性计算器和“其他”等低耦合工具。
7. 最后实现存档编辑、资源导出、自动备份和关闭提示。
8. 对每个字段执行单变量修改，比较保存前后 ROM 字节，形成地址、编码、范围和联动规则表。

## 18. 尚未闭环的实测清单

- 主窗口地图绘制、取样、拖动、图块属性和初始单位部署的准确鼠标手势。
- 商店事件记录的增删改和地图坐标绑定。
- 数据库“人物修改、武器修改、战斗对话、其他修改1、其他修改2”的逐字段清单。
- 地图动画“规律、动画调用”两页的字段和跳转规则。
- 剧情事件六个一级页签、三个事件子页签的增删改、容量和指令编码。
- 保存时自动备份的目录、命名、触发次数和失败处理。
- 导出机体、导出头像的文件格式和命名规则。
- 关闭窗口、切换记录、打开另一 ROM 时的未保存提示。
- 所有数值框的上下限、十进制/十六进制显示、溢出和非法输入反馈。

这些项目必须通过“复制 ROM → 单次操作 → 保存 → 二进制差分 → 重开验证”的方式确认，不能仅凭界面猜测。
